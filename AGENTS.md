# AGENTS.md

The operating rules for this repository are in **[CLAUDE.md](CLAUDE.md)**.

They are tool-neutral despite the filename, and apply to any AI agent or automated contributor:
Claude Code, Copilot, Cursor, Codex, or any other. Read that file before making any change.

They are not duplicated here. A second copy would drift from the first, which is precisely the
failure mode [ADR-0006](docs/adr/0006-single-source-of-truth-documentation.md) exists to prevent.

If a future agent tool requires rules that genuinely differ from those in `CLAUDE.md`, add only the
differences here, with a reference to the rule they modify.
