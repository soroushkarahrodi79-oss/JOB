# JOB — Flexible-Work Marketplace (Foundation)

An investor-grade functional prototype of flexible-work infrastructure for Iran, connecting people
seeking short-duration work with businesses that need reliable workers.

## Status

**GATE 1 — PRODUCT AND INTERACTION DEFINITION.** This repository currently contains documentation
and governance only.

There is no application, no dependencies, and no database. That is intentional. See
[docs/acceptance-gates.md](docs/acceptance-gates.md).
